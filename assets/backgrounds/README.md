# backgrounds 📦 (1920×1080)

三層のアートトーン（§16.2）に対応。webp 推奨。無い場合は単色グラデのプレースホルダ。

| ファイル名 | 用途 | トーン |
|---|---|---|
| `bg_title.webp` | タイトル背景 | — |
| `bg_infirmary.webp` | 医務室ホーム（元チア控室の名残） | 白黒ゴシック寄り |
| `bg_stadium.webp` | 地下球場 | 黒×オレンジ・二色フラット |
| `bg_surgery.webp` | 手術室（無機質＋教会的左右対称） | 白黒ゴシック・重い |

差し替え後 `manifest.ts` の `backgrounds` は変更不要（同名で登録済み）。
