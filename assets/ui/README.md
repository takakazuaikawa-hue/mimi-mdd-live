UIは通常アイコン中心（§17.1）。無い場合は絵文字／CSS図形で代替。

## ダイス5色（§9.5）
形状共通・色違い。webp/png。
| ファイル名 | 色 | 性質 |
|---|---|---|
| `dice_white.webp` | 白 | 通常・標準 |
| `dice_blue.webp` | 青 | 安定・中間値寄り |
| `dice_red.webp` | 赤 | 爆裂・1,6寄り高振幅 |
| `dice_yellow.webp` | 黄 | 同調・ゾロ目寄り |
| `dice_purple.webp` | 紫 | 変異・ランダム特性寄り |
