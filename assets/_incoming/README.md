# _incoming — 画像生成の一時ステージング置き場（必読）

## 採用ポリシー（ユーザー決定）
- **今ゲームに無い画像（新規パス）＝自動採用**してよい。既存を壊さないので、正しいパスへ直接書き出してOK。
- **既存の画像を差し替える（上書き）場合＝必ずこの `_incoming/` に出し、レビューで確認してから**本来のパスへコピーする。**確認なしの直接上書きは禁止。**

## 手順
1. **新規パス**：`docs/IMAGE_GEN_BRIEF_v2.md` の該当箱の**実パスへ直接**書き出す（寸法・透過を厳守）。
2. **既存の差し替え**：`public/assets/_incoming/<用途名>/` に生成 → 人間（アートディレクター）がレビュー → 採用分だけ本来のパスへ**手動コピー**（ファイル名・寸法・透過は変えない）。不採用は残すか削除。

## なぜ
過去に生成AIが既存パスへ直接上書きし、**良い背景・キャラ・ロゴを出来の悪い生成物で潰す事故**が起きた。
「新規＝自動／既存＝確認」で、事故だけを防ぎつつ不足の穴埋めは速く回す。

> 既存インベントリ・差し替え候補・キャラ正典は `docs/IMAGE_GEN_BRIEF_v2.md`、
> 画面ごとの絵作り指示は `docs/DESIGN_MOCK_PROMPT_BRIEF.md` を参照。
