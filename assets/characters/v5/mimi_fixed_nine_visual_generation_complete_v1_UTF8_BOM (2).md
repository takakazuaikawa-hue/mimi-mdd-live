# 7. 画像生成時の共通ネガティブ指示

- 女性化しない
- 子ども化しない
- 老人化しない
- 人外化しない
- 獣人化しない
- バニー耳を付けない
- 過度な筋肉体型にしない
- 全員同じ顔にしない
- 全員同じ髪型にしない
- 白髪にしない
- シュン・花城とミキ・山本以外を金髪にしない
- 余分な腕や脚を付けない
- 初期状態で大規模な機械改造を見せない
- グロテスクな傷口を描かない
- 血まみれにしない
- 装具を隠さない
- 野球ユニフォーム以外の衣装へ変えない
- 守備位置と選手名を混同しない
- 集合絵では人数を9人から増減しない
- 画像内に読めない文字を入れない
- 画像内に実在企業ロゴを入れない
- 実在球団のロゴやユニフォームを使わない
- 体格差を極端にしない
- デフォルメしすぎて個性を失わせない
- 立ち絵では足先や頭頂を切らない
- 背景を過度に描き込み、人物を埋もれさせない

# 8. 制作順の推奨

1. 集合絵を1枚作る
2. 9人の個別立ち絵を1人ずつ作る
3. 個別立ち絵を基準画像として固定する
4. SDデフォルメ版を作る
5. プロフィールUIへ落とし込む
6. 試合画面用の小型シルエットを作る
7. 故障前差分・手術後差分を作る
8. 改造能力ごとの装具・身体差分を追加する

# 9. 画像生成で最優先すること

- 9人の統一感
- 9人の識別性
- 顔立ちの美しさ
- 髪型の差
- 故障部位の明確さ
- 黒×オレンジのチーム感
- 壊れているがまだ戦う空気
- 退廃と熱血の両立
- 初期状態では人間らしさを保つこと
